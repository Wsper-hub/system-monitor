# System Monitor

Маленькое полупрозрачное окно, всегда поверх всех окон, отображающее:

- Загрузку CPU (%)
- Использование RAM (%)
- Скорость сети (приём/передача, KB/s)

Окно можно перетаскивать левой кнопкой мыши, закрыть – через контекстное меню (правая кнопка → Выход).
